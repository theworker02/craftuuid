# craftuuid

Craft identifiers and uuid tokens for idempotent workflows.

**Site:** https://theworker02.github.io/craftuuid/

## Install / run

```bash
git clone https://github.com/theworker02/craftuuid.git
cd craftuuid
node src/cli.js
node --test
```
